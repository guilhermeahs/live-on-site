Política de Privacidade

Última atualização: 22 de setembro de 2026

1. Dados tratados

Quando uma conta TikTok é conectada, o LIVE ON pode tratar os dados autorizados pelo usuário, como identificador da conta, nome de exibição e informações sobre vídeos públicos disponibilizadas pela API do TikTok.

2. Finalidades

Esses dados são utilizados apenas para autenticar a conta autorizada, identificar novas publicações e criar notificações no servidor Discord configurado.

3. Tokens de acesso

Na configuração local do LIVE ON, tokens de acesso e renovação são armazenados no computador em que o aplicativo é executado. O site público não recebe esses tokens.

4. Compartilhamento

O LIVE ON não vende dados pessoais. Informações são transmitidas ao TikTok e ao Discord somente quando necessário para executar as funcionalidades solicitadas e de acordo com as permissões concedidas.

5. Retenção e revogação

O acesso pode ser revogado pelo usuário nas configurações da própria conta TikTok. Tokens locais também podem ser removidos do computador que executa o LIVE ON.

6. Site público

Este site não adiciona cookies de publicidade, pixels de rastreamento ou ferramentas próprias de análise. Ele é hospedado no GitHub Pages, cuja infraestrutura pode processar dados técnicos de acesso conforme as políticas do GitHub.

7. Segurança

São adotadas medidas razoáveis para limitar o acesso às credenciais e utilizar apenas as permissões necessárias. Nenhum sistema conectado à internet pode garantir segurança absoluta.

8. Contato

Dúvidas ou solicitações relacionadas à privacidade podem ser encaminhadas pelo perfil público no GitHub: github.com/guilhermeahs.
